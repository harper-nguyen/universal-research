## 1. Mục tiêu v0.3

Mở rộng Citation Engine v0.2 với khả năng tra cứu metadata học thuật thực sự từ Crossref và OpenAlex. Các nguồn có chứa DOI trong URL được tự động bổ sung tác giả, năm xuất bản, tên tạp chí, và DOI đầy đủ — cho phép định dạng APA 7 hoàn chỉnh mà không bịa đặt thông tin.

## 3. Kiến trúc v0.3

```text
Gemini API Response
  └── grounding_chunks (title, uri)
       │
       ▼
citations.build_source_list()     ← v0.2: dedup, assign citation_id
       │
       ▼ [NEW in v0.3]
enrichment.enrich_sources()
  ├── extract_doi_from_url(url)   ← Tìm DOI trong URL
  ├── lookup_crossref(doi)        ← Crossref API (structured author/year/journal/doi)
  ├── lookup_openalex(doi)        ← OpenAlex API (fallback nếu Crossref thiếu data)
  └── Source fields populated: author, year, journal, doi, metadata_confidence
       │
       ▼
citations.annotate_text_with_citations()   ← inline [N]
citations.build_references_markdown()      ← APA 7 đầy đủ khi metadata có sẵn
```

## 4. Nguyên tắc enrichment

| Nguyên tắc | Áp dụng |
|---|---|
| **Không bịa đặt** | Chỉ điền field khi API trả về data thực |
| **Graceful fallback** | Nguồn không có DOI hoặc API lỗi → Source giữ nguyên |
| **Không ghi đè** | Field đã có giá trị thì không bị overwrite |
| **Confidence tracking** | `metadata_confidence`: `low` → `medium` / `high` sau enrichment |
| **Không có dependency mới** | Dùng stdlib `urllib` — không cần `requests` |

## 6. Giới hạn còn lại

| Giới hạn | Mô tả |
|---|---|
| **Tỷ lệ enrichment** | Chỉ nguồn có DOI trong URL mới được enrichment — phần lớn nguồn web tin tức/chính phủ không có DOI |
| **Enrichment tuần tự** | Mỗi nguồn được tra cứu lần lượt — nếu có nhiều nguồn học thuật, có thể mất vài giây |
| **Timeout** | Mỗi API call giới hạn 5 giây — nếu quá timeout, source giữ nguyên |
| **Tác giả OpenAlex** | Trả về `display_name` không phải `family, given` — có thể không đúng format APA 7 nghiêm ngặt |
