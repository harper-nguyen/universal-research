## 1. Implementation Summary

Universal Research App v0.2 establishes a structured, deterministic citation engine for AI-generated research reports.

### Key Capabilities Introduced
1. **Structured Source Model (`Source`):** Dataclass representing verified source metadata (`citation_id`, `title`, `url`, `domain`, `source_type`, `metadata_confidence`) alongside explicit placeholder fields for future academic enrichment (`author`, `year`, `journal`, `doi`).
2. **Deterministic Citation Numbering:** Sources are deduplicated by normalized URL and assigned 1-based `citation_id`s.
3. **Inline Citation Annotation (`[N]`):** Maps segment-level claim supports from Gemini (`grounding_supports`) to inline `[N]` reference numbers.
4. **Honest APA 7 Formatting:** Formats citations strictly according to available metadata. Never fabricates authors, publication dates, journal names, or DOIs.
5. **Markdown Export:** Exported `.md` reports contain inline `[N]` citations and a complete `## References` section.
6. **Sidebar Citation Style Selector:** Includes APA 7 as default style.

## 5. Known Limitations

1. **Metadata Depth:** `google_search` grounding returns `title` and `uri` only. Authors, publication year, journal name, and DOI are unavailable in v0.2 and set to `None`.
2. **Grounding Support Coverage:** Inline `[N]` citations depend on Gemini returning `grounding_supports`. When unpopulated by the model, the report still receives a complete `## References` section, but inline `[N]` numbers are omitted rather than guessed.
3. **Snippet-level Verification:** Grounding uses Google Search snippets rather than full-page text parsing (as documented in `ARCHITECTURE_AUDIT.md`).

---

## 6. What Was Intentionally NOT Implemented (Out of Scope)

The following were strictly excluded to maintain architectural clarity and avoid unnecessary complexity:
- No web scraping (Playwright, Selenium, BeautifulSoup)
- No external search APIs (Tavily, SerpAPI)
- No vector databases, embeddings, or custom RAG pipelines
- No academic API integrations (Google Scholar scraping, OpenAlex, Semantic Scholar, Crossref, PubMed)
- No automatic PDF downloading
- No authentication or multi-user features
